
# Personal Expense Tracker

A responsive web-based Personal Expense Tracker developed as part of a Web Development – Front-End project.

## Features

- Add expenses
- View expenses
- Delete expenses
- Total expense calculation
- Total transaction count
- Average expense calculation
- Category filtering
- Search functionality
- LocalStorage persistence
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery
- Bootstrap 5
- LocalStorage
